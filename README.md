Vine shot
==============================

this is a 2d stealth game where you have to protect a forest from woodcutters or something( I did this last minute so I didnt give the concept much tought ) 
The controlls are 
WASD to move 
G to grab and move bodies 
shift to crouch
space to dash
and left click to shoot


For running it
----------

1. Install [Godot 4.6](https://godotengine.org/download).
2. Clone this repo.
3. In the Godot Project Manager, click **Import** and pick the `project.godot` file in this folder.
4. Press **F5** to play.
