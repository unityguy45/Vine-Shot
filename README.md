this is a 2d stealth game where you have to protect a forest from woodcutters or something( I did this last minute so I didnt give the concept much tought ) 
The controlls are 
WASD to move 
G to grab and move bodies 
shift to crouch
space to dash
and left click to shoot

How to Play

Woodcutter camps appear in the forest one after another and start chopping trees. Clear all 4 camps before a quarter of the forest is gone. each camp will be bigger than the last if an enemy spots a body the entire camp will be on alert in order to hide bodies you need to drag them into the bushes using G and the camps will calm down 



For running it you need to install Godot 4.6 then clone the repo and then in the godot project manager click import and pick the godot project file and then you can start playing 
or you can download the game on itch io from this link https://hesitant.itch.io/vine-shot
